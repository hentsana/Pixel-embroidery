Основна мета:
Розробити програму для створення схеми української вишивки. Користувач повинен мати змогу інтерактивно обирати кольори з палітри та малювати на сітці клітинок, формуючи власний візерунок. Дані вишивки зберігаються у внутрішній структурі.
Конкретні завдання:
•	При відкритті програми автоматично генерується схема вишивки Вашого імені.

•	Додайте можливість збереження та відкриття схем (наприклад, у форматі PNG).

•	Додайте можливість автоматично будувати схему вишивки з симетрією (горизонтальною, вертикальною), і з дублюванням. Користувач задає розміри, кольори, основний фрагмент орнаменту, який автоматично дублюється з обраною симетрією.

•	Звіт по виконанню роботи.

Опис програми
Програма призначена для створення та редагування схем української вишивки у вигляді піксельного орнаменту. 
Після запуску програми відкривається стартове вікно зі схемою вишивки імені автора у вигляді орнаменту на сітці клітинок. Основне робоче поле являє собою сітку, де кожна клітинка відповідає окремому елементу вишивки. Користувач може обирати кольори з палітри та за допомогою миші зафарбовувати клітинки, створюючи власні візерунки та орнаменти.
Для зберігання даних використовується внутрішня структура даних - двовимірний масив, у якому зберігається інформація про колір кожної клітинки. Це дозволяє швидко змінювати, редагувати та відображати схему.


Структура програми 
•	Пакет pixelempbroidery
Містить основні класи програми для створення та редагування схем української вишивки засобами JavaFX.
•	Клас Launcher
Точка входу в програму.
Містить метод main(), який запускає JavaFX-застосунок через клас StartApplication.
•	Клас StartApplication
Головний клас JavaFX-застосунку, який наслідує Application.
Відповідає за:
1.	створення головного вікна програми;
2.	завантаження стартового інтерфейсу startBanner.fxml;
3.	налаштування сцени та заголовка вікна.
4.	після запуску відкривається стартове меню програми.
•	Клас HelloController
Контролер стартового вікна програми.
Відповідає за:
1.	обробку кнопки запуску редактора;
2.	автоматичне відображення попередньо створеної схеми імені;
3.	завантаження зображення вишивки з ресурсів;
4.	перехід до основного редактора вишивки.
Основні методи:
1.	initialize() — ініціалізація стартового екрана;
2.	loadStartNameDrawing() — побудова схеми вишивки імені;
3.	onStartClicked() — відкриття головного редактора.
•	Клас EmbroideryDrawing
Основний клас редактора піксельної вишивки.
Відповідає за:
1.	створення та редагування орнаменту;
2.	роботу з полотном (Canvas);
3.	обробку натискань миші;
4.	вибір кольорів;
5.	побудову симетричних візерунків;
6.	збереження та відкриття PNG-файлів.

Можливості:
1.	малювання по клітинках;
2.	гумка для стирання;
3.	зміна розміру сітки;
4.	горизонтальна, вертикальна та подвійна симетрія;
5.	очищення поля;
6.	збереження схеми у PNG;
7.	відкриття готової схеми.
8.	Основні методи:
9.	draw() — перемальовування сітки та орнаменту;
10.	handleMouse() — обробка малювання мишею;
11.	symmetryPaint() — автоматичне дублювання елементів;
12.	savePNG() — збереження схеми;
13.	loadPNG() — відкриття PNG-зображення;
14.	clearScrin() — очищення полотна.
•	Для збереження даних використовується двовимірний масив. У ньому зберігається колір кожної клітинки вишивки.

Інструкція для користувача

•	Запуск програми
Після запуску програми відкривається стартове вікно із попередньо згенерованою схемою вишивки імені автора.
Для переходу до редактора необхідно натиснути кнопку:
«Почати роботу з вишивкою»
Після цього відкриється головне вікно редактора.
•	Робота з редактором
Робоча область
У центрі вікна розташована сітка клітинок - поле для створення схеми вишивки. Малювання виконується натисканням або перетягуванням миші по сітці.
Ліва панель інструментів
1.	Вибір кольору
2.	Зміна розміру сітки
3.	Гумка

•	Права панель інструментів
1.	Симетричне малювання
2.	Збереження схеми
3.	Відкриття готової схеми
4.	Очищення полотна
